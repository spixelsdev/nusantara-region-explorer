# 🔒 Kebijakan Keamanan & Pelaporan Kerentanan (Security Policy)

## 1. Lingkup Keamanan (Security Scope)
Proyek **Nusantara Region Explorer** beroperasi sebagai aplikasi web murni berbasis *Client-Side* (SPA).

- **Nol Penyimpanan Database Pribadi:** Aplikasi tidak mengumpulkan, tidak menyimpan, dan tidak mengelola database kredensial, kata sandi, atau NIK/identitas pribadi pengguna.
- **Konsumsi API Eksternal:** Seluruh data yang ditampilkan bersumber langsung dari endpoint publik terbuka (*open data*).

---

## 2. Pelaporan Kerentanan (Reporting a Vulnerability)
Jika Anda menemukan celah keamanan (*security vulnerability*), potensi eksploitasi, kebocoran data, atau masalah kepatuhan pada repositori ini:

1. **JANGAN** membuat *public issue* terbuka di GitHub untuk mencegah eksploitasi oleh pihak yang tidak bertanggung jawab.
2. Silakan hubungi tim pengelola langsung via email:  
   📧 **`yhogieisk66@gmail.com`** atau melalui fitur [GitHub Security Advisories](https://github.com/spixelsdev/nusantara-region-explorer/security/advisories/new).
3. Sertakan detail temuan:
   - Deskripsi kerentanan.
   - Langkah reproduksi (*Proof of Concept*).
   - Dampak potensial.

Kami berkomitmen meninjau dan merilis perbaikan dalam waktu maksimal **2 x 24 jam**.

---

## 3. Perlindungan terhadap Penyalahgunaan (Abuse Protection)
- Dilarang keras memodifikasi kode sumber ini untuk disisipkan skrip berbahaya (*malware*, *keylogger*, *crypto miner*, atau *adware*).
- Dilarang menggunakan repositori ini sebagai media *phishing* atau peniruan identitas lembaga resmi negara.
